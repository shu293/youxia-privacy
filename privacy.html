游匣隐私政策

更新及生效日期：2026年10月23日

《游匣》由漱安开发和运营。联系邮箱：3424083498@qq.com。本政策适用于集成 TapSDK 登录、合规认证、云存档和可选激励广告的 Android 版本。请阅读后自主选择是否同意。未同意前，本游戏不主动初始化 TapSDK、TapADN SDK 或请求其网络服务。不同意可退出应用。

一 账号登录

本游戏通过易玩（上海）网络科技有限公司提供的 TapSDK 4.11.0 进行 TapTap 账号授权登录，请求 basic_info 授权范围，使用游戏内账号唯一标识 openId 区分玩家并关联存档。该范围还包含同厂商账号标识 unionId，本游戏不单独保存 unionId，不主动索取昵称、头像、好友或额外绑定手机号。登录凭证由 SDK 管理，不包含在游戏云存档中。账号的注册、账号信息管理及 TapTap 账号注销由 TapTap 平台提供。

二 实名认证与防沉迷

为履行网络游戏实名和未成年人保护要求，我们接入 TapTap 合规认证。您可按 SDK 流程使用 TapTap 已认证的信息或按其提示完成认证；实名流程可能涉及姓名、身份证件号码等敏感个人信息。请以认证界面明确告知的处理内容为准。本游戏不自建姓名或身份证收集表单，不将上述原始实名材料写入游戏存档。游戏根据认证成功、退出、时段和时长限制等结果决定能否继续游玩，不额外获取真实年龄段。未成年人请与监护人共同阅读相关政策并按认证要求操作；受限制时暂停并保存进度，不允许绕过限制继续游戏。

三 本地记录与云存档

游戏在应用私有目录保存各玩法成绩、游玩记录、关卡进度和未完成对局，并按已登录账号隔离记录。配色、音效等设备偏好另行保存在本地。云存档仅在您主动操作上传或下载时使用，将游戏记录、关卡与对局数据和账号标识关联后传输至 TapTap 云服务；不上传登录凭证、原始实名材料或本地偏好设置。下载会覆盖当前账号本地游戏记录，因此需先确认并保存本地备份。切换账号不会自动把另一账号记录合并进去。旧离线版本记录不会自动上传。

四 SDK 处理与权限

TapSDK 提供者为易玩（上海）网络科技有限公司，接入模块为登录、合规认证和云存档。按 SDK 官方隐私说明，相关服务会处理系统版本、设备型号、设备 CPU 信息、网络类型、AndroidID、设备内存信息及必要的业务请求信息，用于兼容性、故障排查、账号和相关服务运行。本游戏需要 INTERNET 和 ACCESS_NETWORK_STATE 进行上述网络通信，不因这些功能申请定位、相机、麦克风、通讯录或电话读取权限。我们关闭独立事件统计、自动设备登录事件和反射 OAID 的可配置能力，不接入好友或支付模块。
TapSDK 隐私政策：https://developer.taptap.cn/docs/sdk/start/agreement/
关于 SDK 的具体处理和保存说明，请同时阅读该政策。本游戏政策不能代替平台政策，也不会仅凭您同意本政策而启用无关 SDK 模块。

五 保存与删除

本地游戏记录保留至您清空、清除应用数据或卸载。设置中的清空记录只影响本机当前账号，不能代替删除云档；云档由您通过云存档页面单独删除，删除成功后才能确认已清除对应云端记录。卸载或退出登录不会自动删除云档。TapTap 处理的数据存放与保留期限按其服务政策和法定义务执行。您可通过游戏联系邮箱咨询数据删除、访问、更正和投诉事项；涉及 TapTap 账号、SDK 服务记录和认证资料时，我们将说明相应平台处理渠道，不承诺能够直接删除平台依法保留的信息。

六 共享与安全

除提供本政策所述服务所需向 TapTap、TapADN 服务提供方传输的信息外，我们不出售游戏数据、不公开展示您的存档。本版本包含可选的激励广告服务，不包含内购或独立第三方行为统计。游戏数据在传输前进行账号和格式校验，本地使用应用隔离机制保存。请妥善保护设备与账号；删除存档后可能无法恢复。发生个人信息安全事件时，我们依法采取补救、通知与报告措施。

七 您的选择

您可以在账号页面退出游戏登录；如撤回本游戏的隐私同意，可选择撤回同意并退出，停止继续使用 SDK 服务。撤回不影响撤回前合法处理的效力，也不自动删除依法保留的信息。游戏内提供查看政策、本地清空和云档删除入口。主动反馈邮件时，我们处理您的邮箱、正文及主动提供的附件，仅用于答复问题及履行法定义务，请勿发送与问题无关的敏感材料。

八 可选广告服务

激励视频广告由上海艾得蒽数字科技有限公司提供 TapADN SDK 5.3.1.6。在您同意本隐私政策并完成账号登录认证后，游戏自动初始化广告 SDK，并在应用内预加载广告以减少等待时间；在此之前不初始化广告 SDK、不请求广告。视频仅在您主动点击失败后的复活入口或撤销／悔棋按钮后展示。每局最多复活一次；每次复活或撤销均需单独观看一次激励视频并满足 SDK 奖励条件，以 SDK 有效奖励回调为准。提前关闭、跳过或播放失败时，是否满足奖励条件以 SDK 验证结果为准。测试媒体的广告不计收益。

广告 SDK 按官方说明处理设备品牌、型号、系统版本、屏幕密度与分辨率、语言、时区、CPU、可用存储空间、IP 地址、网络状态、应用包名、版本、前后台及运行进程信息、广告展示/点击/转化记录、崩溃及性能数据，用于广告加载、展示、监测归因、统计和反作弊。SDK 政策还列明 OAID 等设备标识；本游戏通过 SDK 隐私控制器关闭 OAID、AndroidID、电话状态、定位、应用列表、Wi-Fi 详情、MAC/SSID/BSSID、传感器及外部存储的可配置采集能力，并关闭摇一摇和个性化广告，不向广告 SDK 传入 TapTap 账号标识或实名材料。不申请定位、电话、存储、应用列表或安装应用权限。

本游戏不提供单独的广告功能开关，您可自主选择不观看激励视频；不点击复活或撤销入口不会主动展示视频，但不代表停止广告预加载及其必要的数据处理。您也可在账号页面撤回本游戏隐私同意并退出，停止后续广告请求并清理待展示广告。已合法处理或依法需保留的数据不会因此自动删除。如需行使相关权利，可联系游戏邮箱或 SDK 提供方。广告 SDK 的保存、共享及第三方广告处理规则详见：https://ssp.dirichlet.cn/docs/agreement/ 。本游戏不接入其他聚合广告 SDK。

若新增其他服务，会在启用前更新政策、明确告知并依法取得必要同意。重大变化通过游戏内显著方式提示。有关本政策和个人信息权利的请求请发至 3424083498@qq.com，运营主体为漱安。我们将在十五个工作日内回复；需要进一步处理时说明情况，您亦可依法向有关部门投诉或寻求其他救济。
